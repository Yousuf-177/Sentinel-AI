# Generated Reports

This directory stores auto-generated PDF security audit reports (Phase 7).

## Expected Output

- `sentinel_report_YYYY-MM-DD.pdf` — Weekly security audit report
  - Alert summary (count by type, severity)
  - Top attacking IPs
  - Mitigation actions taken
  - Time-series charts
  - Model performance statistics

Reports are generated by the ReportLab module in `ml/` and can be triggered:
- Automatically via cron schedule
- Manually via the dashboard or API
